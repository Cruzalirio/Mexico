5  Dependencia temporal y modelos mixtos


Los modelos mixtos permiten combinar efectos fijos, que describen asociaciones promedio para la población, y efectos aleatorios, que representan diferencias entre animales, granjas u otras unidades agrupadas. Esta estructura resulta especialmente apropiada cuando cada animal aporta varias observaciones y los animales se encuentran agrupados dentro de explotaciones.

5.2 Por qué las mediciones del mismo animal están relacionadas


En una base longitudinal, cada animal aparece en varias filas porque se observa repetidamente a lo largo del seguimiento. Las mediciones de un mismo animal suelen parecerse entre sí más que las mediciones de animales diferentes. Esta semejanza puede deberse a características genéticas, edad, estado fisiológico, manejo previo y otras condiciones individuales que persisten durante el estudio.


Los animales de una misma granja también comparten alimentación, instalaciones, clima local, prácticas de manejo y condiciones sanitarias. Por tanto, la base presenta al menos tres niveles:

  1. Mediciones realizadas en diferentes semanas.
  2. Mediciones agrupadas dentro de animales.
  3. Animales agrupados dentro de granjas.


La regresión lineal convencional supone que, una vez incluidas las variables explicativas, los residuos son independientes. Si ignoramos la agrupación, podremos subestimar los errores estándar y obtener intervalos de confianza demasiado estrechos.


Primero prepararemos una base común para los modelos lineales mixtos.

5.4 Modelo nulo con intercepto aleatorio de animal


El modelo mixto más sencillo para el peso no contiene variables explicativas y únicamente incorpora un intercepto general y un intercepto aleatorio para cada animal:

[ {ij} = + b*{0j} + ]


En esta expresión, () es el peso promedio de la población, (b*{0j}) representa la desviación particular del animal (j) respecto al promedio y (_{ij}) es la desviación de la medición (i) respecto al nivel esperado para ese animal.


Código 
modelo_nulo_animal <- lmer(
  peso_kg ~ 1 + (1 | animal_id),
  data = datos_lmm,
  REML = TRUE
)

5.5 Correlación intraclase del animal


La correlación intraclase, o ICC, cuantifica qué proporción de la variabilidad total del peso se atribuye a diferencias entre animales. En un modelo con un único intercepto aleatorio se calcula como:

[ ICC_{animal} = {^2_{animal} + ^2_{residual}} ]


Código 
performance::icc(modelo_nulo_animal)
# Intraclass Correlation Coefficient

    Adjusted ICC: 0.470
  Unadjusted ICC: 0.470


También podemos calcularla directamente a partir de los componentes de varianza.


Código 
var_animal <- as.numeric(
  VarCorr(modelo_nulo_animal)$animal_id[1]
)

var_residual <- sigma(modelo_nulo_animal)^2

ICC_animal <- var_animal /
  (var_animal + var_residual)

ICC_animal
[1] 0.4695652


Un ICC próximo a cero indica que las mediciones del mismo animal no son mucho más parecidas que las mediciones de animales diferentes. Un ICC alto indica una semejanza importante dentro de cada animal y confirma que la independencia de todas las filas sería una aproximación inadecuada.


5.6 Interceptos aleatorios de animal y granja


Además de las diferencias individuales, puede existir variabilidad entre granjas. Ajustaremos un modelo nulo con interceptos aleatorios para granja y animal.


Si animal_id es único en toda la base, podemos utilizar dos términos separados:

[ {ijk} = + u*{0k} + b{0jk} + _{ijk} ]


Aquí, (u_{0k}) representa la desviación de la granja (k) y (b_{0jk}) representa la desviación del animal (j) respecto a su granja.


Código 
modelo_nulo_dos_niveles <- lmer(
  peso_kg ~ 1 +
    (1 | granja_id) +
    (1 | animal_id),
  data = datos_lmm,
  REML = TRUE
)

La varianza de granja representa diferencias sistemáticas entre explotaciones. La varianza de animal representa diferencias entre animales después de considerar su granja. La varianza residual representa diferencias entre mediciones del mismo animal que el modelo todavía no explica.

6 Bloque 5. GLMM y respuestas no continuas


6.1 Diferencia entre un modelo lineal mixto y un GLMM


El modelo lineal mixto utilizado en el bloque anterior es apropiado cuando la respuesta es cuantitativa continua y puede representarse razonablemente mediante una distribución normal alrededor de la media. El peso, expresado en kilogramos, es un ejemplo de este tipo de respuesta.


Un modelo lineal generalizado mixto, o GLMM, amplía esta estructura para respuestas que no son continuas ni normales. Algunos ejemplos son:

  • Respuestas binarias, como presencia o ausencia de una condición.
  • Conteos, como el número de visitas veterinarias.
  • Proporciones, como el número de animales enfermos entre los examinados.


Un GLMM combina tres elementos:

  1. Una distribución para la respuesta, como binomial o Poisson.
  2. Una función de enlace que relaciona la media con los predictores.
  3. Efectos aleatorios para representar la agrupación y las mediciones repetidas.


Para una respuesta binaria utilizaremos una distribución binomial y un enlace logit. El modelo se expresa como:

[ ( ) = +* 1X*{1ijk} + + u_k+b{jk} ]


La cantidad (p_{ijk}) es la probabilidad de que la observación presente el resultado de interés. El término (p/(1-p)) corresponde a las odds, y su logaritmo es el logit.


6.2 Construcción de una respuesta binaria


La base contiene una puntuación de salud de 0 a 4. Para fines didácticos construiremos una respuesta binaria denominada salud_alta_bin, que tomará el valor 1 cuando la puntuación sea igual o superior a 3 y el valor 0 cuando sea inferior a 3.


Este punto de corte es una decisión didáctica. En una investigación real debería definirse mediante criterios clínicos, productivos o previamente establecidos, y no seleccionarse después de observar los resultados.


Código 
datos_glmm <- datos_b2 |>
  select(

    granja_id,
    tiempo,

  mutate(

      as.character(salud_score_0_4)

      is.na(salud_num) ~ NA_real_,

6.15 Limitaciones del GLMM binario


La transformación de una puntuación ordinal de 0 a 4 en una respuesta binaria simplifica el análisis, pero también elimina información. Las puntuaciones 0, 1 y 2 quedan agrupadas, al igual que las puntuaciones 3 y 4.


Si la escala ordinal tiene significado científico, un modelo ordinal mixto podría ser más apropiado. La elección entre un análisis binario y uno ordinal debe basarse en la pregunta científica y en la definición del resultado, no únicamente en la facilidad del análisis.


El modelo supone además que el cambio temporal es lineal en la escala logit y que los efectos del consumo, la edad y la semana son iguales para todos los animales. También supone que la estructura aleatoria de interceptos representa suficientemente la dependencia. Estas hipótesis deben revisarse y justificarse.


6.16 Resumen de interpretación del GLMM


Para comunicar un modelo logístico mixto conviene indicar:

  3. Cuáles fueron los efectos fijos incluidos.
  4. Qué unidades se representaron mediante efectos aleatorios.
  5. Cuáles son las categorías de referencia.

  7. Probabilidades predichas para escenarios interpretables.
  8. Los componentes de varianza y la importancia de la agrupación.
  9. Los resultados de convergencia y singularidad.
  10. Las limitaciones de convertir una respuesta ordinal en binaria.

Al finalizar estos bloques debemos comprender por qué las mediciones repetidas requieren métodos que representen su dependencia. El modelo lineal mixto permite analizar una respuesta continua, como el peso, incorporando diferencias entre animales y granjas. El GLMM amplía esta estructura para respuestas no continuas, como una condición binaria de salud.


Los efectos fijos resumen asociaciones promedio, mientras que los efectos aleatorios describen variabilidad entre las unidades agrupadas. En la regresión logística mixta, los coeficientes pueden transformarse en odds ratios, pero su interpretación debe complementarse con probabilidades predichas y con una descripción clara de las categorías de referencia y del evento analizado.
