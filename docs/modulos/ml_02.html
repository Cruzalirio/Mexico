9  Métodos de regresión y clasificación


En este capítulo construiremos modelos predictivos de regresión y clasificación con los datos de animales y granjas. Utilizaremos regresión lineal para predecir el peso y regresión logística para predecir una respuesta binaria de salud. Después introduciremos la regularización y evaluaremos el desempeño mediante métricas calculadas en animales no utilizados durante el entrenamiento.

9.3 Regresión lineal para predecir peso


Código 
receta_peso <- recipe(
  peso_kg ~
    consumo_kg_dia + consumo_agua_l_dia +
    edad_inicio_meses + sexo + raza + tiempo +
    temperatura_C + humedad_pct + precipitacion_mm +
    actividad_h_dia + sistema_produccion + zona,
  data = train_ml2
) |>
  step_unknown(all_nominal_predictors()) |>
  step_novel(all_nominal_predictors()) |>
  step_dummy(all_nominal_predictors()) |>
  step_zv(all_predictors()) |>
  step_normalize(all_numeric_predictors())

modelo_lm_ml <- linear_reg() |>
  set_engine("lm")

flujo_lm <- workflow() |>
  add_recipe(receta_peso) |>
  add_model(modelo_lm_ml)

ajuste_lm <- fit(
  flujo_lm,
  data = train_ml2
)

El RMSE penaliza especialmente los errores grandes. El MAE representa el error absoluto medio en kilogramos. El (R^2) predictivo describe cuánto se aproximan las predicciones a los valores observados en el conjunto de prueba.

9.4 Regularización mediante elastic net


La regularización reduce la magnitud de los coeficientes para controlar la complejidad. La penalización mixture = 0 corresponde a ridge, mixture = 1 a lasso y los valores intermedios a elastic net.


Código 
modelo_glmnet <- linear_reg(
  penalty = tune(),
  mixture = tune()
) |>
  set_engine("glmnet")

flujo_glmnet <- workflow() |>
  add_recipe(receta_peso) |>
  add_model(modelo_glmnet)

rejilla_glmnet <- grid_regular(
  penalty(range = c(-5, 0)),
  mixture(range = c(0, 1)),
  levels = c(20, 5)
)


Código 
set.seed(2026)
resultados_glmnet <- tune_grid(
  flujo_glmnet,
  resamples = folds_ml2,
  grid = rejilla_glmnet,
  metrics = metric_set(rmse, mae, rsq),
  control = control_grid(save_pred = TRUE)
)

show_best(
  resultados_glmnet,
  metric = "rmse",
  n = 10
)

La exactitud puede ser engañosa cuando las clases están desequilibradas. La sensibilidad representa la proporción de mediciones con salud alta identificadas correctamente. La especificidad representa la proporción de mediciones sin salud alta clasificadas correctamente. El AUC ROC evalúa el ordenamiento de las probabilidades a través de todos los umbrales.

9.7 Selección del umbral


El valor 0,5 no es obligatorio. Puede elegirse otro umbral según el costo de falsos negativos y falsos positivos.


Código 
umbral <- 0.35

pred_logistica_umbral <- pred_logistica |>
  mutate(
    clase_umbral = factor(
      if_else(.pred_Sí >= umbral, "Sí", "No"),
      levels = levels(salud_alta_ml)
    )
  )

metric_set(sens, spec, accuracy)(
  pred_logistica_umbral,
  truth = salud_alta_ml,
  estimate = clase_umbral,
  event_level = "second"
)
