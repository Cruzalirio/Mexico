11  Introducción a las redes neuronales


En este capítulo introduciremos las redes neuronales mediante un perceptrón multicapa para predecir el peso de los animales. El objetivo no es construir una arquitectura profunda, sino comprender las neuronas, las capas ocultas, las funciones de activación, el entrenamiento y el riesgo de sobreajuste.

11.2 De la regresión lineal a una red neuronal


Una regresión lineal calcula una combinación ponderada de predictores. Una neurona realiza una operación semejante, pero aplica una función de activación. Al combinar varias neuronas en capas ocultas, la red puede representar relaciones no lineales complejas.


Para una capa oculta podemos expresar una neurona como:

[ h_j = g(b_j + ^{p}w*{jk}x_k) ]


La salida de la red combina las activaciones de las neuronas ocultas para producir una predicción.


11.3 Preprocesamiento


Las redes neuronales son sensibles a las escalas. Estandarizaremos todos los predictores numéricos y convertiremos las variables categóricas en indicadores.


Código 
receta_nn <- recipe(
  peso_kg ~
    consumo_kg_dia + consumo_agua_l_dia +
    edad_inicio_meses + sexo + raza + tiempo +
    temperatura_C + humedad_pct + precipitacion_mm +
    actividad_h_dia + sistema_produccion + zona,
  data = train_nn
) |>
  step_unknown(all_nominal_predictors()) |>
  step_novel(all_nominal_predictors()) |>
  step_dummy(all_nominal_predictors()) |>
  step_zv(all_predictors()) |>
  step_normalize(all_numeric_predictors())

receta_nn


11.4 Perceptrón multicapa


Utilizaremos nnet, que ajusta una red con una única capa oculta. El parámetro hidden_units controla el número de neuronas ocultas y penalty introduce regularización sobre los pesos.


Código 
modelo_nn <- mlp(
  hidden_units = tune(),
  penalty = tune(),
  epochs = tune()
) |>
  set_engine(
    "nnet",
    trace = FALSE,
    MaxNWts = 20000
  ) |>
  set_mode("regression")

flujo_nn <- workflow() |>
  add_recipe(receta_nn) |>
  add_model(modelo_nn)

11.9 Visión general del aprendizaje profundo


El aprendizaje profundo utiliza redes con varias capas y un gran número de parámetros. Estas arquitecturas son especialmente útiles para imágenes, audio, texto, secuencias extensas y grandes volúmenes de datos.


En ciencias animales podrían utilizarse para clasificar imágenes de lesiones, analizar vídeo de comportamiento, procesar sonidos, reconocer animales o modelar secuencias de sensores. Para la tabla actual, una red profunda probablemente sería innecesaria y podría sobreajustarse.


11.10 Límites e interpretación


Las redes neuronales presentan varias limitaciones:

  • Requieren preprocesamiento y selección cuidadosa de hiperparámetros.
  • Pueden cambiar con la inicialización aleatoria.
  • Su interpretación es menos directa que la de una regresión.
  • Necesitan más datos y cálculo cuando aumenta la profundidad.
  • No corrigen automáticamente la dependencia entre mediciones repetidas.
  • Una alta precisión no implica causalidad.


11.11 Actividad de interpretación


  1. ¿Qué operación realiza una neurona?
  2. ¿Qué aporta una función de activación?
  3. ¿Por qué deben estandarizarse los predictores?
  4. ¿Qué controla hidden_units?
  5. ¿Qué función cumple la penalización?
  6. ¿Qué representa el número de épocas?
  7. ¿La red mejora el RMSE respecto a la regresión lineal?
  8. ¿El error es estable durante el seguimiento?
  9. ¿Por qué una red más grande puede sobreajustar?
  10. ¿Qué tipos de datos justificarían aprendizaje profundo?
