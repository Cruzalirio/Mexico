4  De la regresión lineal simple a la múltiple


En este bloque utilizaremos la regresión lineal para estudiar la relación entre el peso de los animales y distintas variables explicativas. Comenzaremos con un modelo sencillo en el que el peso se explica únicamente mediante el consumo de alimento. Después incorporaremos la edad, el sexo, la raza y la semana de seguimiento para construir un modelo de regresión múltiple.


El objetivo es comprender cómo cambia la interpretación de los coeficientes cuando pasamos de una relación entre dos variables a un modelo con varios predictores. También estudiaremos los intervalos de confianza, el coeficiente de determinación, los residuos, la heterocedasticidad y las limitaciones de aplicar una regresión convencional a datos longitudinales.


Los modelos de este bloque se utilizarán con fines didácticos y exploratorios. La base contiene mediciones repetidas del mismo animal y animales agrupados dentro de granjas. La regresión lineal convencional no representa adecuadamente esas dependencias, pero constituye un punto de partida útil antes de introducir los modelos mixtos.

Para comparar correctamente los modelos, utilizaremos una misma base de casos completos. De este modo, las diferencias entre los resultados no se deberán a que cada modelo haya utilizado un número distinto de observaciones.


Código 
datos_modelo <- variables_modelo |>
  drop_na(
    peso_kg,
    consumo_kg_dia,
    edad_inicio_meses,
    sexo,
    raza,
    tiempo
  ) |>
  mutate(
    sexo = droplevels(as.factor(sexo)),
    raza = droplevels(as.factor(raza)),
    tiempo_c = tiempo - mean(tiempo),
    edad_inicio_c = edad_inicio_meses -
      mean(edad_inicio_meses)
  )

# Número de filas y unidades representadas.
datos_modelo |>
  summarise(
    n_filas = n(),
    n_animales = n_distinct(animal_id),
    n_granjas = n_distinct(granja_id)
  )
# A tibble: 1 × 3
  n_filas n_animales n_granjas
    <int>      <int>     <int>
1   48452        500        50


Las variables tiempo_c y edad_inicio_c son versiones centradas de la semana y la edad inicial. Centrar una variable consiste en restarle su media. Este procedimiento no modifica su asociación con el peso ni la pendiente estimada, pero facilita la interpretación del intercepto.


Con las variables centradas, el intercepto del modelo múltiple corresponde al peso esperado para un animal de las categorías de referencia, con consumo igual a cero si el consumo no se centra, edad inicial promedio y situado en la semana promedio. Más adelante centraremos también el consumo para obtener un intercepto biológicamente más interpretable.


4.2 Exploración inicial del peso y el consumo


Antes de ajustar una regresión, debemos representar gráficamente la relación entre la variable de respuesta y la variable explicativa. El diagrama de dispersión permite observar si la relación parece aproximadamente lineal, si existen valores extremos y si la variabilidad del peso cambia a lo largo del rango de consumo.


Código 
ggplot(

  aes(x = consumo_kg_dia, y = peso_kg)
) +

    alpha = 0.15,
    size = 1,

  ) +

La línea representa el peso medio estimado para cada nivel de consumo. La banda muestra la incertidumbre asociada a la estimación de esa media. No representa el rango dentro del cual se encontrará el 95 % de los animales individuales.


También podemos calcular la correlación de Pearson entre ambas variables como una primera medida de asociación lineal.


Código 
cor_consumo_peso <- cor(

La correlación resume la intensidad y la dirección de la asociación lineal, pero no permite ajustar por edad, sexo, raza o semana. Tampoco distingue las diferencias entre animales de los cambios que ocurren dentro de un mismo animal a lo largo del tiempo.


4.3 Regresión lineal simple


En una regresión lineal simple relacionamos una variable de respuesta cuantitativa con una única variable explicativa cuantitativa. En este caso, utilizaremos el peso como respuesta y el consumo diario de alimento como predictor.


La ecuación general del modelo es:

[ _i = _0 + _1_i + _i ]


En esta expresión, (_0) es el intercepto, (_1) es la pendiente y (_i) representa la parte del peso que el modelo no explica para la observación (i).


Código 
modelo_simple <- lm(
  peso_kg ~ consumo_kg_dia,
  data = datos_modelo
)

summary(modelo_simple)

El coeficiente de consumo_kg_dia representa el cambio medio esperado en el peso, expresado en kilogramos, asociado con un incremento de 1 kg/día en el consumo de alimento.


Si la pendiente es positiva, las mediciones con mayor consumo tienden a presentar mayor peso. Si es negativa, las mediciones con mayor consumo tienden a presentar menor peso. Esta interpretación describe una asociación y no demuestra que aumentar el consumo produzca directamente el cambio estimado en el peso.


El intercepto representa el peso medio estimado cuando el consumo es igual a cero. Aunque es necesario para construir la recta, puede carecer de interés biológico si un consumo de cero se encuentra fuera del rango observado o no corresponde a una situación compatible con el diseño del estudio.


Podemos comprobar el rango de consumo para valorar si el intercepto implica una extrapolación.

4.4 Predicciones del modelo simple


Una vez ajustado el modelo, podemos utilizarlo para estimar el peso medio correspondiente a determinados niveles de consumo. Seleccionaremos tres valores representativos: el primer cuartil, la mediana y el tercer cuartil.


Código 
nuevos_consumos <- tibble(
  consumo_kg_dia = quantile(
    datos_modelo$consumo_kg_dia,
    probs = c(0.25, 0.50, 0.75),
    na.rm = TRUE
  )
)

predicciones_media <- predict(
  modelo_simple,
  newdata = nuevos_consumos,
  interval = "confidence",
  level = 0.95
)

bind_cols(

  as.data.frame(predicciones_media)
)

El intervalo de confianza se refiere al peso medio esperado para las observaciones con un nivel determinado de consumo. Si queremos predecir el peso de una observación individual, debemos incorporar también la variabilidad residual mediante un intervalo de predicción.

El intervalo de predicción es más amplio que el intervalo de confianza porque incluye tanto la incertidumbre de la media estimada como la variabilidad de las observaciones individuales alrededor de la recta.


4.5 Coeficiente de determinación


El coeficiente de determinación (R^2) representa la proporción de la variabilidad observada en el peso que queda descrita por los predictores incluidos en el modelo.


Un (R^2) próximo a 0 indica que el modelo explica poca variabilidad del peso. Un valor próximo a 1 indica que las predicciones del modelo reproducen una proporción elevada de la variabilidad observada. Sin embargo, un (R^2) alto no demuestra causalidad ni garantiza que se cumplan los supuestos de la regresión.

En la regresión simple, el (R^2) coincide con el cuadrado de la correlación de Pearson entre el peso y el consumo, siempre que el modelo incluya intercepto y se utilicen las mismas observaciones.

  correlacion_al_cuadrado = cor_consumo_peso^2

El (R^2) ajustado incorpora una penalización por el número de predictores. En un modelo con una sola variable explicativa suele ser muy parecido al (R^2), pero cobra mayor importancia al comparar modelos múltiples con distinto número de variables.


4.6 Incorporación de la edad

En este modelo, el coeficiente del consumo representa la diferencia media esperada en el peso asociada con un incremento de 1 kg/día en el consumo, comparando observaciones con la misma edad inicial.

4.10 Intervalos de confianza de los coeficientes


Un intervalo de confianza del 95 % presenta un rango de valores compatibles con los datos y el modelo utilizado. Un intervalo estrecho indica mayor precisión, mientras que uno amplio indica mayor incertidumbre.


Podemos representar los coeficientes del modelo múltiple y sus intervalos de confianza. Excluiremos el intercepto porque utiliza una escala diferente y suele dificultar la visualización de los demás coeficientes.


Código

Cuando un intervalo incluye el valor cero, los datos son compatibles con asociaciones positivas, negativas o muy pequeñas bajo las condiciones del modelo. No debemos interpretar automáticamente este resultado como demostración de ausencia de relación.


La magnitud del coeficiente debe interpretarse en las unidades originales de cada variable. Por tanto, no es correcto comparar directamente el tamaño numérico de coeficientes expresados por kilogramo de consumo, mes de edad y semana de seguimiento.

4.12 Valores ajustados y residuos


Para cada observación, el modelo produce un valor ajustado y un residuo. El valor ajustado es el peso estimado por el modelo. El residuo es la diferencia entre el peso observado y el peso ajustado:

[ e_i = y_i - _i ]


Un residuo positivo indica que el peso observado es superior al estimado. Un residuo negativo indica que el peso observado es inferior al estimado.

4.13 Diagnóstico de linealidad y heterocedasticidad


Uno de los principales gráficos de diagnóstico representa los residuos frente a los valores ajustados. Si la relación lineal y la varianza constante son aproximaciones razonables, los residuos deberían formar una nube sin patrones claros alrededor de cero.


Código 
ggplot(
  diagnostico_multiple,
  aes(x = .fitted, y = .resid)
) +
  geom_point(

  geom_hline(
    yintercept = 0,

Un patrón curvo puede indicar que alguna relación no es lineal. Una forma de embudo, en la que la dispersión de los residuos aumenta o disminuye con el valor ajustado, puede indicar heterocedasticidad.


La heterocedasticidad aparece cuando la varianza de los residuos no es constante. Por ejemplo, el modelo podría cometer errores pequeños en animales de bajo peso y errores mucho mayores en animales pesados.


Podemos utilizar también el gráfico de raíz de los residuos estandarizados absolutos. Una tendencia ascendente sugiere que la dispersión aumenta con los valores ajustados.

4.15 Observaciones atípicas e influyentes

4.18 Límites de la regresión lineal convencional


La regresión lineal convencional supone que, una vez consideradas las variables explicativas, los residuos son independientes. Este supuesto no es razonable en nuestra base longitudinal.


Cada animal aparece en múltiples semanas. Las mediciones de un mismo animal tienden a parecerse porque comparten características biológicas, genéticas y de manejo. Además, los animales de una misma granja comparten alimentación, ambiente y sistema productivo.


Podemos visualizar esta repetición calculando cuántas observaciones aporta cada animal y cada granja a la base usada por el modelo.


Código

Cuando tratamos todas las filas como independientes, el modelo puede sobreestimar la cantidad de información disponible. Como consecuencia, los errores estándar pueden ser demasiado pequeños y los intervalos de confianza excesivamente estrechos.


Además, la regresión convencional combina dos tipos de asociación:

  1. Diferencias entre animales: los animales que consumen más en promedio pueden pesar más que otros animales.
  2. Cambios dentro del animal: un animal puede pesar más en las semanas en las que consume más que su propio promedio.


Estos dos procesos no tienen necesariamente el mismo significado biológico ni el mismo coeficiente. Para separarlos y representar la correlación de las mediciones repetidas, necesitaremos modelos mixtos con efectos aleatorios para animal y granja.

4.20 Resumen de interpretación del modelo múltiple


Para comunicar los resultados de una regresión múltiple conviene seguir un orden claro:

  1. Identificar la variable de respuesta y las variables explicativas.
  2. Indicar las unidades de las variables cuantitativas.
  3. Señalar las categorías de referencia de las variables categóricas.
  4. Interpretar cada coeficiente manteniendo constantes las demás variables.
  5. Presentar los intervalos de confianza para describir la precisión.
  6. Informar el (R^2) y el (R^2) ajustado sin interpretarlos como pruebas de causalidad.
  7. Revisar los residuos y las observaciones influyentes.
  8. Reconocer las limitaciones derivadas del diseño longitudinal y jerárquico.

4.21 Actividad de interpretación


A partir de los modelos y gráficos anteriores, responda las siguientes preguntas:


  1. ¿La relación entre consumo de alimento y peso parece aproximadamente lineal?
  2. ¿Cómo se interpreta el coeficiente del consumo en el modelo simple?
  3. ¿Tiene sentido biológico interpretar el intercepto del modelo simple?
  4. ¿Cómo cambia el coeficiente del consumo al incorporar la edad?
  5. ¿Cuáles son las categorías de referencia para sexo y raza?
  6. ¿Cómo se interpreta un coeficiente asociado con una categoría de raza?
  7. ¿Qué representa el coeficiente de la semana en el modelo múltiple?
  8. ¿Qué diferencia existe entre un intervalo de confianza y un intervalo de predicción?
  9. ¿Cuánto aumenta el (R^2) al pasar del modelo simple al modelo múltiple?
  10. ¿El aumento del (R^2) implica que el modelo múltiple sea causalmente correcto?
  11. ¿Los residuos muestran curvatura, forma de embudo o valores extremos?
  12. ¿La variabilidad de los residuos parece constante?
  13. ¿Existen observaciones potencialmente influyentes?
  14. ¿Qué limitación produce la repetición de mediciones del mismo animal?
  15. ¿Por qué un modelo mixto sería más apropiado para estos datos?


Al finalizar este bloque debemos ser capaces de ajustar e interpretar una regresión lineal simple y una regresión múltiple, explicar los coeficientes y sus intervalos de confianza, diferenciar el (R^2) del (R^2) ajustado y revisar los principales gráficos de residuos.


También debemos reconocer que una regresión convencional no representa adecuadamente la estructura longitudinal y jerárquica de la base. El paso siguiente consistirá en incorporar efectos aleatorios para considerar las diferencias entre animales y granjas, así como la correlación entre observaciones repetidas.
