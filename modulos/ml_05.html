10  Capítulo 5. Segmentación y reducción de dimensionalidad


En este capítulo utilizaremos métodos no supervisados para identificar perfiles de granjas y representar su semejanza en pocas dimensiones. Trabajaremos con una fila por explotación, porque el objetivo es segmentar granjas y no agrupar las miles de mediciones repetidas de los animales.


Los conglomerados son construcciones algorítmicas. No deben convertirse automáticamente en categorías biológicas o administrativas. Su interpretación requiere revisar las variables utilizadas, la escala, la estabilidad y la distribución geográfica de los grupos.

10.2 Selección y estandarización de variables


K-means utiliza distancias euclidianas. Si no estandarizamos, las variables con escalas numéricas grandes dominarán la formación de los grupos.


Código

  select(
    peso_medio,

receta_cluster <- recipe(~ ., data = variables_cluster) |>

10.3 Número de conglomerados


No existe un único criterio universal. Compararemos la suma de cuadrados interna y la silueta media.


Código 
fviz_nbclust(
  matriz_cluster,
  kmeans,
  method = "wss",
  k.max = 8
) +
  labs(
    title = "Método del codo"
  )


Código 
fviz_nbclust(
  matriz_cluster,
  kmeans,
  method = "silhouette",
  k.max = 8
) +
  labs(
    title = "Silueta media según el número de grupos"
  )


El método del codo busca un punto a partir del cual añadir grupos reduce poco la variabilidad interna. La silueta combina cohesión dentro del grupo y separación frente a los demás grupos.

10.8 Clustering jerárquico


El clustering jerárquico comienza con cada granja como un grupo separado y fusiona progresivamente los grupos según una regla de enlace.


Código 
distancias_granjas <- dist(
  matriz_cluster,
  method = "euclidean"
)

modelo_jerarquico <- hclust(
  distancias_granjas,
  method = "ward.D2"
)

plot(
  modelo_jerarquico,
  labels = perfiles_granja_ml$granja_id,
  main = "Dendrograma de las granjas",
  xlab = "Granja",
  sub = "Método de Ward"
)

rect.hclust(
  modelo_jerarquico,
  k = k_seleccionado,
  border = 2:4
)


Código 
perfiles_granja_cluster <- perfiles_granja_cluster |>
  mutate(

Una silueta próxima a 1 indica buena asignación. Valores cercanos a 0 indican posiciones fronterizas. Valores negativos sugieren que la granja podría estar más próxima a otro grupo.
